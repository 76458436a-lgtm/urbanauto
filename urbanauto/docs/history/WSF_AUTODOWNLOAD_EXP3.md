# Urban Auto Exp 5.4 exp3 – проверяемая загрузка WSF

В Processing выберите «Urban Auto Exp – скачать WSF Tracker по области карты».

1. Укажите опорный растр, год и каталог вывода.
2. Для получения бинарной маски **вручную укажите коды класса застройки** из официальной легенды конкретного набора WSF. Без кодов сохраняется только исходный выровненный растр. Нельзя считать, что код 1 означает застройку без проверки.
3. Алгоритм проверяет полное покрытие по GDAL validity mask и записывает встреченные коды в `wsf_source_manifest.json`. При пробелах прекращает работу, не заменяя NoData фоном.
4. Полученный `WSF_Tracker_<год>_binary.tif` можно передать в «Urban Auto Exp – сравнение с WSF по точкам» вместе с бинарным растром Urban Auto и независимыми контрольными точками.

Ограничения: автопоиск работает только если STAC DLR предоставляет прямые GeoTIFF. Работа с реальным DLR и QGIS не подтверждена в тестовой среде. Не сравнивайте разные определения застройки без согласования эталона. Если коды классов неоднозначны, оставьте поле пустым и изучите манифест.
