# Urban Auto Exp – 5.4.0-exp1

Экспериментальная ветка Urban Auto Exp 54 [EXP] 5.2. Базовая модель 5.2 не менялась.

## Что добавлено

В меню «Городской анализ» и Processing → Urban Auto Exp доступен инструмент «сравнение с WSF по точкам». Он сравнивает бинарную карту Urban Auto с **локально подготовленным** бинарным растром WSF на одинаковых независимых контрольных точках, выдаёт `comparison_points.csv` и `benchmark_metrics.json` (OA, κ, F1, precision, recall, исправленные/испорченные точки).

## Как запускать

1. Установить ZIP через QGIS → Модули → Управление и установка → Установить из ZIP. Не устанавливать одновременно со старой версией с тем же внутренним ID `urban_auto_exp54`.
2. Получить WSF из официального источника и самостоятельно привести к бинарной маске: 1 – застроенная территория, 0 – фон. **Не передавать исходные категориальные или датированные значения WSF без преобразования.**
3. Подготовить бинарный GeoTIFF Urban Auto: 1/0; обеспечить единое определение класса для двух карт и точек.
4. Подать в алгоритм обе карты, независимые точки с полем 0/1 и папку результата. Перепроецирование координат точек при выборке происходит автоматически; растры не пересчитываются.
5. Проверить количество исключённых точек и обе матрицы ошибок в JSON.

## Ограничения

- WSF **не скачивается автоматически**; онлайн-загрузка и гибридная коррекция пока не реализованы.
- Точечные метрики без весов выборки не равны площади с поправкой Olofsson. Для оценки площади нужен отдельный дизайн выборки и веса страт.
- Для корректного сравнения определение «территория застройки» должно совпадать. WSF может исключать дворы и зелёные зоны внутри кварталов.
- Сравнение 2025 года не подтверждает точность года появления застройки.
- Ветку не проверяли в работающем QGIS; синтаксис Python проверен отдельно. Требуется интеграционный тест на Windows/QGIS 3.34+.
- Точки, использованные для подбора параметров, нельзя повторно выдавать за независимую валидацию.

## План следующей итерации

Импорт WSF с явной интерпретацией классов; карта расхождений; независимая валидация с весами страт; затем осторожный гибридный алгоритм с отдельным обучением и holdout.
