# Проверка выпуска 4.3.0

Дата: 31 октября 2026 года.

## Выполнено

- Синтаксический разбор/компиляция Python-файлов.
- Разбор metadata.txt и XML формы интерфейса.
- 17 численных регрессионных тестов: сохранение последнего прироста, удаление неподтверждённого раннего пятна, монотонность и неизменность исходных масок, ошибочные годы/формы/типы, матрица OSM, пересечение эталонных классов, некорректные площади, отсутствие наблюдений, единицы шахматки, Оцу, K-Means для отрицательных спектральных значений и малого городского класса, поиск/полнота/неоднозначность наборов файлов.
- 4 интеграционных теста в QGIS 3.34.4 (GDAL 3.8.4, Python 3.12, Linux, offscreen):
  1. Автономная обработка трёх лет с разным разрешением индексов, NoData внутри застройки, сохранением последнего прироста, возобновлением и отклонением изменённых исходников.
  2. Регистрация и запуск пакетного алгоритма Processing, площадная оценка точности по идентичному эталону, отклонение перекрывающихся эталонных буферов до начала обработки.
  3. Запуск алгоритма одного года и отдельного алгоритма временной согласованности с проверкой статуса и прироста последнего года.
  4. Строгая сетка отклоняет разные разрешения.
- Создание окна UrbanAutoDialog и проверка автоматических начальных настроек.
- Отдельный CLI-запуск трёхлетнего ряда: успешный код завершения, итоговый JSON, CSV/GPKG, положительный последний прирост.

Полный набор: **21 тест, OK**, корректное завершение процесса. При испытаниях был обнаружен и исправлен дефект формирования temporal_status в отчёте отдельного Processing-алгоритма. Дополнительно устранена проблема времени жизни временных растров: их провайдеры закрываются до удаления файлов. Недопустимые буферы оценки точности проверяются до запуска алгоритма.

## Что не проверено

Это проверка программного поведения на искусственных данных, **не оценка точности классификации реальных городов**. Фактические снимки и исходные растры Урая в ZIP отсутствуют. Не выполнены новый расчёт ВКР, независимая полевая/визуальная валидация, тесты Windows и установленной у автора QGIS 3.44, нагрузочные испытания, проверка сетевых серверов OSM и обработка крупных сцен.

## Повторение

В Python из среды QGIS, из родительского каталога плагина:

```bash
python -m unittest discover -s urban_auto_exp54/tests -v
```

Для чисто численных проверок достаточно обычного Python с NumPy; интеграционные тесты без QGIS будут помечены как skipped. Запускать их следует в отдельном тестовом процессе, а не в уже открытой интерактивной сессии QGIS.
