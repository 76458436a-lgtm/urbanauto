# Urban Auto Exp 54 – отдельный модуль

Версия: 5.4.0-exp6. Основа: предоставленный UrbanAutoExp54.zip.

Установка: QGIS → Модули → Управление и установка модулей → Установить из ZIP.
Выберите UrbanAutoExp54_5.4.0-exp6.zip и включите «Urban Auto Exp 54 (отдельный модуль)».
Основной модуль можно оставить включённым.

Отдельная папка: urban_auto_exp54.
Отдельный провайдер: urban_auto_exp54 (у основного urban_auto).
Меню: Urban Auto Exp 54 [EXP]. Все 8 алгоритмов имеют префикс [EXP 54].
Пометки добавлены в заголовок окна, отчёты, журнал и добавляемые в проект слои.
Собственный глобальный кэш: .urban_auto_exp54_cache.
Для сравнения расчётов задавайте разные папки результатов: имена выходных файлов сохранены для совместимости расчётного кода.

Примеры Processing: urban_auto_exp54:batch_folder, urban_auto_exp54:rf_series,
urban_auto_exp54:wsf_benchmark, urban_auto_exp54:wsf_download.

Старые результаты проверки точности в TESTING.md относятся к исходной версии и не были повторены при разделении модулей.

Версия exp5: параметры главного окна прокручиваются; кнопки запуска и закрытия закреплены внизу. Размер окна подстраивается под экран.

В exp6 алгоритм Processing rf_series позволяет выбрать основной источник Sentinel-2 для интервала с 2018 г. Для воспроизведения эксперимента 5.3 задайте размер пикселя 10 м и отдельную папку композитов. Параметр ADAPTIVE_EDGE включает предварительные даты появления в конце ряда. Обычный запуск сохраняет строгое правило подтверждения. Обоснование режимов, ограничения и результаты приведены в VALIDATION.md.
